# 素材清单与来源

每个素材是**真实素材**还是**占位**，直接决定成片能不能对外发。
改片之前先对一遍这张表。

---

## 真实素材（可以对外）

| 素材 | 路径 | 规格 | 来源 |
|---|---|---|---|
| 品牌标志 | `brand/mark.png` 等 | 910×910 透明 | 设计源文件 |
| 矢量环 | `brand/eprolo-ring.svg` | 矢量 | 按实测几何重画 |
| 商品卡 | `wall/w01–16.png` | 206×292 ×16 | **从后台录屏按网格精确裁切** |
| 后台截帧 | `panels/p0.70 / p1.50 / p2.20.png` | 1544×868 | 寻源录屏的干净段（0.65–2.3s） |
| 平台图标 | `assets/icons/*.png` | 各 50–178px | eprolo.com |
| 商品图 | `assets/p/1–3.png` | 301×321 | 官网商品页截取 |
| 商品卡横排 | `assets/plate-a/b/row.png` | 1564×880 | 官网商品列表横排（带价格） |

`wall/` 是怎么来的：录屏是 1920×1144，商品卡网格列宽 214、行高 300，
逐帧检测卡片顶边的 y 偏移后按格子裁，共采 4 个滚动位置、每位置 4 列 × 3 行，
剔除掉鼠标指针压住的、被任务栏污染的、内容不全的，剩 16 张。

## 占位素材（不能对外）

| 素材 | 位置 | 问题 |
|---|---|---|
| 贴牌盒子 / 吊牌 / 感谢卡 | `index.html` 第 8 段，22–27s | **代码绘制的矢量图形**，不是实物。等实物拍摄替换 |
| 协作四宫格 | 第 9 段，27–29.2s | 半占位，用的 `assets/p/m1–m3.png` 只有 300px，放大后会软 |
| 利润数字 | 第 7 段 | 41% 毛利是按真实商品价格算的，但**是模型推算，不是客户实测** |

贴牌三件套的原始图（`贴牌3件套1-3.jfif`，250×250）是 **POD 印刷模板**（橙色 "YOUR DESIGN" 占位框），
不是品牌视觉素材，所以只当作小尺寸商品缩略图用，没有当成贴牌案例。

## 素材缺什么

按优先级：

1. **贴牌实物照**（盒子 / 吊牌 / 感谢卡），白底或浅灰底，2000px 以上 → 解决第 8 段占位
2. **一屏结构不同的后台截图**：渠道绑定、批量上架各自一屏。
   现在的 16 张卡都是同一个商品列表页的不同滚动位置，能证明"品多"，证明不了"能绑定渠道"和"能批量上架"
3. **矢量版字母 e**（AI/EPS），解决 `eprolo-mark.svg` 里唯一的位图
4. **真实客户数据**（可选）：留评数、复购率之类，比"41% 毛利"更有说服力
