# 动效规格 · 当前版本

这份是**权威参数**。改动画前先看这里，不要从画面反推。
版本：v2（2026-11-26），对应 `stinger.html` 与 `index.html` 的现状。

---

## 一、公共规范

```
画布      1920 × 1080
品牌绿    #31CB49   (RGB 49,203,73)
墨色      #16211B
底色      #FAFBF9
字体      "Helvetica Neue", Arial, sans-serif
```

字体是系统无衬线，**没有引入 webfont**。原因是导出时无头 Chrome 不保证加载外部字体，
一旦字体异步到达，同一时间点两次渲染会出不同结果，逐帧导出就会跳。要换成品牌字体，
必须转成 base64 内嵌，不能走 `<link>`。

### 缩放：为什么是 0.168

内容收束的终点必须**正好落进环的内孔**：

```
1105（遮罩圆半径）× 0.168 = 185.6
MD/2 - STK/2 = 220 - 17.1 = 202.9   ← 环内缘半径
```

185.6 略小于 202.9，留了 17px 呼吸。小于 0.12 内容会糊成一团色块，大于 0.25 会顶到环壁。

### 手接点：全片最关键的一处

```js
// 0.30–0.42：二次加速，把速度从 0 提到 PUSH_V
const PUSH_V = 0.55;                            // 对数尺度/秒
const PUSH_A = PUSH_V / (2 * 0.12);             // = 2.29
scale = exp(PUSH_A * d * d);                    // d = t - 0.30
// d = 0.12 时：scale = 1.0335，速度 = 2·A·d = 0.55

// 0.42 起：弹簧承接，初值、初速完全一致
scale = exp(spr(t - 0.42, ln(1.0335), ln(0.168), 0.62, 10, 0.55));
```

两段在 0.42 处**位置相等、速度相等**。少任何一个，观众就会看到"停一下，再被拽走"。
这是 v1 被判"卡"的头号原因——旧版是纯弹簧从静止起步，ω²×行程 让前两帧从 0 直接冲到全速。

### 遮罩为什么要 1105

商品墙在离屏画布拼成 7 列 × 5 行、单卡 270px（间距 18），尺寸 2016×2054，
整体放大到 2260px 边长（`WK = 2260 / min(WW,WH)`），再用半径 **1105** 的圆 clip。

- 画面半对角 = √(960² + 540²) = 1102 ＜ 1105 → s=1 时遮罩完全看不见，仍是满幅；
- s 一降，四角先被切，瞬间变成圆盘，**没有"方形浮块"的中间态**；
- 收敛终点 1105 × 0.168 ≈ 185.6，正好塞进环内孔。

这三个数是一组，改任何一个另外两个都要跟着调。

### 运动模糊

`SHUTTER = 0.10 / FPS`（约 36°）。实现是 running average：

```js
// 第 k 张子帧 alpha = 1/(k+1)，数学上等于快门积分
for (k = N-1; k >= 0; k--) draw(subframe k, alpha = 1/(k+1));
```

**别调大。** 试过 223°（0.62 帧），商品网格会糊成一片"热浪"——因为每张卡的位移方向都不同，
眼睛无法把它读成整体运动，只看到沸腾。极短快门只保留方向感，够了。

### 可调参数

| 名字 | 现值 | 调大 | 调小 |
|---|---|---|---|
| `ζ` (zeta) | 0.62 | 更收敛、几乎不弹 | 弹更久、更"软" |
| `ω` (omega) | 10 | 更快更硬 | 更慢更飘 |
| `PUSH_V` | 0.55 | 吸气更明显 | 更平顺、接近无预推 |
| `SHUTTER` | 0.10 帧 | 更糊（慎用） | 更锐 |
| `DUR` | 2.30 | 尾部定格更长 | 更利落 |

`export.js --to` 必须与 `DUR` 对齐，否则尾部会被截断或多出静止帧。

### 第 3 段的滚动参数

```js
SC_A = 4.92, SC_B = 6.38;   // 滚动窗口
SC_D = 4500;                // 纵向滚动距离（px，墙内坐标）
scroll = SC_D * eInOut(p);  // 88 个商品在 1.46s 内穿过窗口
zoom   = 1.015 + 0.03*p + 0.055*eOutC(ph(t,6.40,7.30));
```

模糊同样用逐帧平均，采样数由速度自适应（`min(26, dyFrame/5.5)`），峰值单帧位移 146px。

### 第 8 段的盒子动效

`BX=1372, BY=748, BW=250, BD=115, BH=210`（等轴测盒）。
节奏：蓄力（下压 0.94）→ 下落 → 落地 squash（1.06/0.94）→ 回弹 → 涟漪。
`landElastic = cos(t·ω)·e^(−t·k)` 做衰减震荡，参数见函数定义。

## 四、导出

```bash
node serve.js 8731        # 必须先起服务
node export.js --page stinger.html --fps 60 --from 0 --to 2.30 --crf 15 --out out/stinger.mp4
```

`export.js` 通过 CDP 调用页面的 `window.__frame(t)`，把 PNG 直送 ffmpeg 编码。
页面在 `?export=1` 下不跑 `requestAnimationFrame`，完全由外部驱动时间，所以**逐帧确定**。

已知坑：脚本曾用固定 `--user-data-dir`，Chrome 走磁盘缓存，**改了代码导出的还是旧版**。
现已加 `&v=Date.now()` 破缓存。遇到"改了没反应"，先查这条。
