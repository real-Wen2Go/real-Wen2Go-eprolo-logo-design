# EPROLO 30s Motion Board · v2

16:9 / 1920×1080 / 30.03s / 10 段。基于 `motion.md`（Canva Visual Suite 2.0 发布片）的分镜节拍改写。

## 怎么用

```bash
node serve.js 8731
# 打开 http://127.0.0.1:8731/index.html
```

- `空格` 播放/暂停　`←/→` 逐帧　`1–9` 跳段
- 底部进度条可拖拽，章节按钮直接跳段
- 单帧出图：`index.html?still=17.4`（可加 `&t=` 定格）

## 导出成片

```bash
node serve.js 8731          # 另开一个终端，导出需要本地服务
node export.js --fps 30 --out out/eprolo-30s.mp4
```

- 原理：无头 Chrome + CDP，逐帧调用页面里的 `?export=1` 钩子（`window.__frame(t)`），
  用 `Page.captureScreenshot` 抓 1920×1080 PNG，直接 pipe 给 ffmpeg 编码，不落中间文件。
- 输出：H.264 High / yuv420p / bt709 / CRF 16 / 30fps / 901 帧 / 5.1MB，**无声**。
- 速度：约 220ms/帧，全片 3.5 分钟。
- 参数：`--fps 60`（更顺，导出时间翻倍）、`--from 22 --to 27`（只出某段）、`--crf 12`（更高画质）。
- 每次改完动画重新导出即可，不需要重新设计。


## 后台段（4.4–8.6s）商品墙极速下滑

素材换成从 `产品多.mp4`（eprolo 后台 All Products 页，1920×1144@60）里**按卡片网格精确裁切**的 16 个真实商品卡：

- 网格实测：列起点 x=637 + i×214，行起点 y 由每帧的卡片顶边检测得出，卡面 206×292（含图/标题/价格/运费）
- 裁到 `wall/w01..16.png`，底部 70px 亮度检测排除掉沾到 Windows 任务栏的废帧
- `buildWall()` 把它们拼成 5 列 × 8 行、宽 1348px 的商品墙（左右各 46px 余量，防止推近时切卡片），
  行距 358px = 卡高 340 + 间距 18，**总高 2864 正好 8 行整**，所以纵向可以无缝循环滚动

滚动曲线：`scrollAt(t)` = 4500px × `eInOut`（4.92→6.38s），即 17 排 / 88 个商品在 1.46s 内穿过窗口，
峰值约 4600px/s（≈150px/帧）。

**动态模糊**用「逐帧平均」而不是叠影：第 i 层 `alpha = 1/i`、纵向偏移 `-dyFrame·(i-1)/N`，
N 帧平均后等于快门积分，得到真正的运动模糊（之前那种"主体 α=1 + 拖影 α=0.3"只会糊在上下边缘，
因为连续纹理被主体完全盖住）。N 由速度自适应，峰值 26 层、每层间隔 ≈5.5px，单帧位移上限 146px；
采样点少了会数得出"一层层重复的卡片"，所以宁可贵一点也要把 N 拉满。
无头 Chrome 忽略 `ctx.filter`，这条是唯一可行路径。代价：峰值帧 370ms，全片约 5.5 分钟。

推近：`1.015 + 0.03·滚动进度 + 0.055·eOutC(6.40→7.30)`，即滚动中缓推、停下后再补一个短促推近到 1.10。

界面反馈（都压在滚动内容之上）：
- 4.98–6.38 右上角计数胶囊 `200,000+ products`，数字随滚动从 0 涨到 20 万
- 6.40–7.28 左下 toast「Added to import list」
- 7.10–7.52 居中「12 products selected → Import to store」
- 左侧 248px 品类导航（All Products / US Warehouses / … / Cars & Motorcycles）固定不动，压在滚动内容上

试片：`out/seg-wall.mp4`

## 品牌收束片 · "e for everything."（stinger.html）

独立于 30s 主片的品牌 sting，1920×1080 / **1.90s** / 60fps，可做片头、片尾、社媒收尾。

### 文件
- `stinger.html` — 动画本体（单文件 canvas，`?still=t` 看单帧，`?export=1` 供导出）
- `brand/e-only.png` — 从 mark.png 按半径 318 抠出的字母，环完全去掉
- `brand/wordmark.png` — 从 lockup-plain.png 裁出的纯字标（730×153）
- `out/stinger.mp4` — 成片（H.264 CRF15 / 6.2MB）
- 导出：`node export.js --page stinger.html --fps 60 --from 0 --to 1.9 --out out/stinger.mp4`

### 几何（实测 mark.png 910×910）
| 项 | 值 | 用途 |
|---|---|---|
| 环外径 | 910（满画布） | 标志直径基准 |
| 环厚 | 74 = 8.14% | 按 D 等比缩放 |
| 环中线半径 | 417.5 = 0.4588 D | arc 半径 |
| 内孔径 | 760 = 83.5% | 内容收束的终点 |
| 缺口 | 33°（视觉），端点 ±21.4° | 圆头端点各占 4.9° |
| 字母最大半径 | 283 = 62% | e 的绘制尺寸 |

### 关键机制：内切圆遮罩
商品墙按 270px 卡片拼成 7×5，**整体放大到 2260px**（`WK = 2260/min(WW,WH)`），
再用半径 **1105** 的圆做 clip——这个圆刚好内切于墙，所以：
- s=1 时圆半径 1105 > 帧半对角 1102，遮罩完全看不见，仍是满幅；
- s 一降，四角先被切掉，画面立刻变成圆盘；全程没有"浮在空中的矩形"阶段。
> 这是这一版最关键的修正。若遮罩圆比墙大，收缩到一半会露出墙的直角边。

### 缩放曲线
`S0=1.030 → S1=0.168`，**对数空间**插值，缓动 `e = p^1.6`（加速）。
线性插值会让前 60% 时间看着不动，最后一帧跳掉。
S1=0.168 的依据：1105 × 0.168 = 185.6 ≈ 环内径 184.6，圆盘正好落进环口。

| 0.22–0.34 | 蓄力 1.000→1.030 |

### 踩过的坑
1. 环形一开始用固定半径，结果它像加载圈浮在大圆盘上；必须让它随圆盘收缩。
2. 内容淡出与字母淡入重叠 160ms，两层都半透明 → 出现"绿灰脏影"；改成 60ms 硬交接。
3. 环内残留的绿色辉光会让 logo 内部发绿，必须提前到 1.00s 前收干净。

## stingerv2 · 修「卡」

v1 的问题不是丢帧，是运动本身：逐帧测量（480×270 灰度，帧间平均绝对差）显示
1.9 秒里峰值 23.4 出现在 0.47s，而 **0.85s→1.9s 全程 ≈0**，等于 1.4 秒冻住。

### 三个真因与对策

| 真因 | 现象 | 对策 |
|---|---|---|
| 所有运动挤在 0.5s 内，前奏与尾段全静止 | 看两秒静止后突然暴动，眼睛读成掉帧 | 时间线重排到 2.30s，运动铺满 0.30–1.90 |
| 缓动是幂函数、终点高速硬停 | 「顿」一下，没有落地感 | 换成**解析阻尼振子**（ζ=0.62，ω=10），自带过冲与衰减 |
| 弹簧从静止起步 | ω²·行程 的初加速度过大，前一帧不动、后一帧全速 | 用**速度连续**的预推：0→0.55 对数尺度/秒，交接点位、速严格相等 |

### 关键实现：速度连续的手接

```
0.00–0.30  scale = 1，只做 50px 匀速上浮
0.30–0.42  scale = exp(A·d²)，d = t−0.30，A = 0.55/0.24
           → 交接点 scale = 1.0335，速度 = 0.55（对数/秒）
0.42+      scale = exp(spr(t−0.42, ln1.0335, ln0.168, ζ0.62, ω10, v0=0.55))
```
两段的**位置和速度在 0.42 处都相等**，所以没有「停一下再被拽走」的顿感。
`spr()` 是解析解，确定性、可任意 t 采样 —— 导出管线必须如此。

### 旋转
0.30→0.72 用 `eInOutS` 拧到 −22°（两端速度为 0，加速度有限），
0.72 起用弹簧弹回 0，过冲 +1.8°。
> 不能用 `eOutC`：它在起点速度最大，等于「瞬间获得角速度」，必然顿一下。

### 运动模糊
`SHUTTER = 0.10 帧`（36°）。曾经试 0.62 帧（223°），结果商品网格糊成热浪 ——
**径向/缩放模糊作用在密集网格上非常难看**，因为每张卡片的位移方向都不同，
眼睛无法把它读成一个整体运动，只看到「沸腾」。极短快门只留一点方向感，够了。
实现是 running average：第 k 张子帧 alpha = 1/(k+1)，数学上等于快门积分。

### 导出坑
`export.js` / `shot.js` 用固定 `--user-data-dir`，Chrome 会走磁盘缓存，
**改了代码导出的还是旧版**。已加 `&v=Date.now()` 破缓存。
以后再遇到「改了没变化」，先查这一条。

### 可调参数
- `ζ`（0.62）：阻尼比。0.5 弹更久，0.8 几乎不弹
- `ω`（10）：刚度。越大越快越硬
- `PUSH_V`（0.55）：交接速度，决定「吸气」有多明显
- `SHUTTER`：模糊长度
- `DUR`：总长，尾部定格可自行拉长
