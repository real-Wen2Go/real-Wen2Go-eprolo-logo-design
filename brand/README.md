# 品牌素材

## 色值

```
品牌绿  #31CB49     RGB 49, 203, 73
墨色    #16211B     RGB 22, 33, 27
底色    #FAFBF9
```

只有这三个。绿色不要自己调明暗——需要深浅变化时用透明度，不要改色相。

## 文件

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `eprolo-mark.svg` | 矢量 | **推荐**。完整标志：矢量环 + 内嵌字母 |
| `eprolo-ring.svg` | 矢量 | 只有环，纯路径，可改 `stroke` 染色 |
| `mark.png` | 910×910 | 完整标志，透明底 |

| `wordmark.png` | 730×153 | 纯字标 EPROLO，无图标、无域名，透明底 |
| `lockup.png` | 1011×250 | 横版组合（环 + 字标） |
| `lockup-plain.png` | 1011×250 | 横版组合，已去掉下方域名 |
| `mark-src.png` / `lockup-src.png` | — | 原始文件，未处理，留档 |

## 几何（实测，不是估的）

以 910×910 的 `mark.png` 为基准：

| 项 | 值 | 归一化 |
|---|---|---|
| 环外径 | 909 | 1.000 D |
| 环线宽 | 74 | 8.14% D |
| 环中线半径 | 417.5 | 45.88% D |
| 环内径 | 760 | 83.5% D |
| 缺口（视觉） | 33° | — |
| 弧端点 | ±20.4° | — |
| 圆头端帽 | 4.94°/端 | — |
| 字母包围盒 | 344 × 481，起于 (283, 238) | 37.8% × 52.9% D |
| 字母最大半径 | 283 | 62.3% D |

圆心在 (468.5, 454.5)，**不在画布正中**——环的外缘恰好内切画布上下边，
所以垂直方向顶格，水平方向右移了 13px。`eprolo-mark.svg` 完整保留了这一偏移，
与 PNG 逐像素比对差异 0.83%（基本是边缘抗锯齿）。

### 复用到别的地方时

任何尺寸下这四个比例都成立，照抄即可：

```js
const R   = D * 0.4588;   // 环中线半径
const STK = D * 0.078;    // 环线宽
const GAP = 21.4 * Math.PI / 180;   // 弧端点（含端帽补偿）
```

缺口在**右侧**，从右上 20.4° 到右下 20.4°，圆头收尾。画环的路径：

```js
ctx.lineWidth = STK; ctx.lineCap = 'round';
ctx.arc(cx, cy, R, GAP, Math.PI*2 - GAP); ctx.stroke();
```

## 已知缺口

**字母 e 没有矢量版。** `eprolo-mark.svg` 里的环是纯路径（可无限缩放），
但字母是内嵌的 base64 位图——因为原始素材只有位图，机器描摹会让边缘抖动。

要真正的全矢量标志，需要向设计要 AI / EPS / 带轮廓的 PDF 源文件，
或者确认字母出自哪套字体（看形态是几何无衬线的定制字，直接找同款字体不一定对得上）。
在此之前，位图在 440px 显示尺寸下（源 481px）是够用的，再放大就会软。
